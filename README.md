# Bike Store

## Video Demo: https://youtu.be/3lLTrBkouUE

## Description:

bike_store is a web-based e-commerce and inventory management system developed as my final project for CS50. Built by Ahmed omar abbas from Baghdad, Iraq (GitHub: mra792925), the application provides a streamlined storefront for browsing and purchasing bicycle parts while maintaining real-time stock accuracy in a relational database.

The project consists of several core components designed to ensure smooth functionality. The backend is powered by Python and the Flask framework, handling all application routes, managing HTTP GET and POST requests, validating inventory availability during purchases, and executing SQL queries against the database. The database is structured using SQLite to persistently store product catalogs, user data, and order history across dedicated relational tables.

The user interface utilizes HTML templates rendered dynamically via Jinja2 syntax to present responsive product cards and purchase forms, styled cleanly with CSS stylesheets. Additionally, the system incorporates robust logic to prevent overselling by verifying item stock prior to logging transactions and deducting quantities instantly upon checkout.
